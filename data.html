How to Read the 4-Digit Codes

Each team is assigned a 4-digit binary code that captures four dimensions of performance:

1st digit — Offensive Level: 1 = good offense (above median), 0 = bad offense (below median)

2nd digit — Defensive Level: 1 = good defense (below median, since lower is better), 0 = bad defense

3rd digit — Offensive Consistency: 1 = consistent offense (low rugosity), 0 = inconsistent offense

4th digit — Defensive Consistency: 1 = consistent defense (low rugosity), 0 = inconsistent defense

For example, a team coded 1111 has good offense, good defense, and is consistent on both ends — an "Elite Machine." A team coded 0000 has poor and inconsistent performance across all four dimensions — "Full Rebuild Mode."
